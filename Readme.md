# NODEJS BACKEND TEMPLATE

This Node.js Backend Template follows module based architecture and has complete auth and database support.

# TECHNOLOGIES USED

- **Backend:** Node.js, TypeScript
- **Framework:** Express.js
- **Database:** PostgreSQL
- **ORM:** Drizzle ORM
- **Validation:** Zod
- **Logging:** Winston
